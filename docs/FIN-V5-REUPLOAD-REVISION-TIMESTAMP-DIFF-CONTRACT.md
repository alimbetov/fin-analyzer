# FIN V5 — повторная загрузка отчётности, история версий и время

**Дата:** 2026-11-16. **Ветка:** feat/fin-r0-r1a. **Статус:** первая серверная реализация для F02 MANUAL, остальные формы и серверный XLSX — позже.

## 1. Бизнес-правила

Отчёт идентифицируется комбинацией organizationId, projectId, formCode, reportingBasis, periodType, periodCode и valueCoverage. Язык Excel и версия пользовательских переводов **не создают новую финансовую форму**. При повторном вводе той же формы за тот же период сравниваем нормализованные значения с последней черновой ревизией.

| Результат проверки | Операция |
|---|---|
| NEW | Подтвердить первую ревизию v1 |
| DUPLICATE | Сохранить событие повторной загрузки с временем, но НЕ увеличивать номер ревизии |
| CHANGED | Показать поэлементный Diff, потребовать причину изменения, после подтверждения создать новую vN |
| REVISION_CONFLICT | Отклонить старое подтверждение HTTP 409 и предложить проверить актуальную ревизию |
| Invalid | Не изменять предыдущие данные, показать причины и адреса ячеек при XLSX |

Автоматически заполнять отсутствующие поля прежними значениями запрещено. Смешение валют, покрытия периода или масштаба денег без отдельной утвержденной политики — блокирующая ошибка.

## 2. Две даты, а не одна

- **uploadedAt** — точное серверное время приёма валидированного Preview (TIMESTAMPTZ UTC); в журнале может существовать и для повторной идентичной загрузки.
- **savedAt** — точное серверное время подтверждения новой ревизии (TIMESTAMPTZ UTC).
- **revisionNumber** — порядковый номер, присвоенный только успешно созданной ревизии. При повторной загрузке одинакового файла остаётся прежний номер.
- **inputLocale** — язык исходного документа; **displayLocale** — язык представления таблицы, не влияет на values или revisionNumber.
- Браузер отображает UTC-время в часовом поясе пользователя с явной зоной. Клиентское время в локальном пилоте не считается аудиторским серверным временем.

## 3. Реализованный серверный contract

Flyway V11 добавляет отдельные объекты: project_v5, form_slot_v5, preview_v5, draft_revision_v5 в схеме fin_intake. Foreign keys учитывают organizationId; триггеры запрещают менять и удалять project, preview и draft_revision. Для одной логической формы сохраняется целочисленный указатель latest_revision, проверяемый при транзакционном подтверждении.

FormDraftRevisionV5Service реализует createProject, previewManual, confirm, history, readRevision и uploads. Validation использует опубликованный F02 TSV-каталог и точную BigDecimal-нормализацию. Diff возвращает before/after для каждого fieldCode с состояниями ADDED, CHANGED, UNCHANGED. Хеш нормализованных значений не зависит от языка исходного файла.

Для сохранения требуются expectedRevision, confirmationDigest, организация, проект и субъект загрузки. Повторное подтверждение того же Preview идемпотентно. Конкурентное подтверждение устаревшего Preview возвращает REVISION_CONFLICT. Версии v1 и v2 имеют отдельные immutable cells, parentRevisionId, uploadedAt, savedAt, uploadedBy, savedBy, changeReason, fingerprint. Для изменения после v1 причина обязательна.

Защищённые методы представлены в FormDraftRevisionV5Controller на пути /api/v1/financial/organizations/{organizationId}/projects-v5. Действующие FIN_SUBMIT/FIN_READ, JWT и FinanceAccessPolicy остаются обязательными: анонимный обход запрещён. Предварительный результат не является APPROVED source, FactSetRevision или финансовым заключением.

## 4. UI и пользователю

В локальном пилоте F02 React показывает номер предлагаемой ревизии, время загрузки, таблицу было/стало, обязательную причину корректировки и историю версий с датами загрузки и сохранения. Это история **текущей вкладки**, её нельзя выдавать за PostgreSQL-историю предприятия. Файл JSON явно помечен LOCAL_UNVERIFIED_DRAFT.

Полноценная постоянная история доступна из PostgreSQL через защищённые history, uploads и history/{revisionNumber}. После подключения реальной React авторизации UI должен отображать именно серверный uploadedAt/savedAt и загружать старые значения по revisionNumber, а не хранить их только в памяти.

## 5. Непременно остаётся вне этого инкремента

- Серверный безопасный Apache POI импорт Excel V2; browser ExcelJS не является доказательством серверного источника.
- Подключение React к настоящему projectId/JWT workflow и отображение долговечной серверной истории.
- F01, F03, DF-CSH-01/02, все другие 166 каталожных позиций, дополнительные типы периода и валютные конвертации.
- Автоматическое утверждение источников, изменение уже опубликованных FactSetRevision, повторная публикация прежнего отчёта задним числом.
- Полноценный DiagnosticPresentationService RU/KK/EN/zh-Hans; выделен в Issue #13.
