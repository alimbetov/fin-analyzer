# FIN — полный каталог 166 форм и вопросы для исследования методик

**Источник названий:** `form-library/src/main/resources/catalog/editorial-titles-{finance,details,sector}-r15.tsv`.  
**Контроль состава:** `docs/FIN-CALC-R0-COVERAGE-166-BASELINE.tsv`.  
**Ветка:** `feat/fin-form-library-standalone`. **Состояние:** исследовательский реестр, без финансового S2.  

Каталог содержит **154 числовые формы** и **12 документальных форм**. Названия скопированы из каталога FIN; «Что проверить» — вопросы для поиска, не утверждённая методика и не подтверждение работоспособности соответствующих вычислений.

В [редактируемой TSV-таблице](./FIN-CALC154-ALL166-FORMS-NAMES-METHODOLOGY-RESEARCH.tsv) добавлены поля `selectedMethodologyUser`, `sourceStandardAndClauseUser`, `controlExampleUser` для заполнения после сбора методик.

**В первую очередь:** C01/C02; C03/C04/C05; F01/F02/F03/F06; P04/P06/P07/P08/P09. Для P07 выбор FCFF/FCFE должен связывать поток с WACC/Ke и Enterprise/Equity Value в одной версии сценария. Не распространять DCF как обязательную методику на P01–P10 без основания.

## Как передавать решения для реализации

Для каждой формы укажите **код**, **вариант методики**, **источник и точный пункт/версию**, **параметры и их единицы**, **контрольный пример с исходными и ожидаемыми числами**, а также **область применения (проект, сценарий, валюта, период)**. Если есть несколько допустимых вариантов, укажите все, но не выбирайте обязательный вариант без учётной политики.

Пример для `P07`:

- `DCF_FCFF_WACC`: входы FCFF по датам, WACC, terminal value, оценка предприятия.
- `DCF_FCFE_KE`: входы FCFE по датам, cost of equity, terminal value, оценка собственного капитала.
- Дополнительный параметр `terminalMethod` может быть `GORDON_GROWTH` или `EXIT_MULTIPLE` (должны быть однозначные правила расчёта).
- `P07` не содержит числового ряда денежных потоков в собственных физических полях: он ссылается на cashflow revision. Потребуется контракт разрешения и сверки этой ссылки.

Это требования к методологии и данным, **не** заявление о выполненном расчёте или независимом S2.
