# ADR-010 — FIN Project Marketplace: основное название платформы

**Дата:** 2026-11-15 · **Статус:** ACCEPTED — продуктовый нейминг; NOT IMPLEMENTED как готовая платформа.

## Решение

**FIN Project Marketplace** — основное название всей B2B-платформы для самостоятельной экономической диагностики, создания бизнес-планов, проектов, поиска инвесторов, банков, консалтинговых фирм и партнёров, адресного обмена отчётностью и мониторинга.

**FIN Analyzer** — встроенный экономико-аналитический модуль (финансовые, инвестиционные, отраслевые методы, правила интерпретатора). Не использовать его как равноправное название всей платформы.

| Продуктовый раздел | Назначение |
|---|---|
| FIN Analyzer | Экономические и финансовые расчёты, диагностика, интерпретатор |
| «Мой бизнес» | Действующая деятельность, KPI, продажи, отчётность |
| «Мой проект» | Стратегический план, бизнес-план, инвестиционные модели |
| Project Discovery | Публичные разрешённые карточки проектов, поиск и сравнение |
| FIN Connect | Кабинеты организаций, переписка, запросы материалов |
| Report Center | Финансовые отчёты, версии, публикация, приглашения |
| Access Center | Зоны, время, одноразовый доступ, отзыв, аудит |
| Trust & Admin | Подтверждение полномочий, модерация, методология |

**FIN Project Marketplace — информационная B2B-платформа, не биржа и не финансовый посредник.** Деньги не принимаются, не хранятся и не переводятся; биржевые торги и исполнение инвестиционных сделок вне продукта (ADR-007). Международная публикация инвестиционных проектов требует отдельной правовой оценки содержания предложений и модели посредничества.

Техническая основа: React + Spring Boot BFF + FIN PostgreSQL, отдельная Keycloak PostgreSQL, backend-only Redis, RustFS и KumoMTA; доступы — ADR-009.

Сохраняем текущие GitHub owner/repository, исторические ветки, документные пути и PR. Не создавать переименований, ломать ссылки и историю только ради нового названия.

**Acceptance:** главное ТЗ/README именуют FIN Project Marketplace основной платформой; FIN Analyzer — модулем; роли, формы и публикации относятся к платформе; не заявлять ничего из планируемых функций реализованным.
