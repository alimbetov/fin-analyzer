## QA-R1-01

1. Открыть библиотеку, выбрать `DF-AST-01`, добавить строку.
2. Вставить `9 007 199 254 740 993,123456789123` в `capacity` и сохранить.
3. На исходной версии получен HTTP 422 в Chromium. После исправления HTTP 200 и в редакторе отображается точное значение `9007199254740993.123456789123`.

[Браузерный regression test](../../frontend/e2e/decimal-input.spec.ts) воспроизводит ввод выше предела точных целых JavaScript Number, с 12 дробными знаками. Нормализация остаётся строковой, допускает явно сгруппированные пробелами значения и сохраняет отказ для неоднозначной короткой записи вида `1,234`. Ограничения точности и валютного масштаба остались на стороне сервера.

## Ограничения выпуска

- Для 31 формы нужна квалификация финансового контракта перед открытием записи. Производственная квалификация S2 отсутствует у всех 166 текущих версий. Разрешённая запись создаёт предварительные редакции, включая F02.
- Организация и проект входят в scope локального отчёта. Spring Security и проверка личности отсутствуют по архитектуре localhost UAT. Отказы при несовпадении scope не дают доказательства IAM или tenant isolation.
- [Исходный аудит FIN R1](../audits/FIN-R1-QUALITY-AUDIT-166-FORMS-2026-11-18.md) содержит методологические и редакционные замечания по единицам, обязательности, метрикам и переводам. Для утверждения решений нужны владельцы финансовых контрактов.
