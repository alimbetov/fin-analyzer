[Поформенная матрица фактического прогона](FIN-FORM-QA-R1-TEST-MATRIX.md) показывает категории, число полей и результат. [Существующий реестр форм](../audits/FIN-R1-166-forms-quality-summary.csv) содержит заголовки RU/KK/EN/ZH-Hans, версии, режимы, типы, обязательность и кандидатные условия квалификации. [Реестр физических полей](../audits/FIN-R1-166-forms-field-quality-877.csv) описывает типы, единицы, метрики и статусы проверки. [Реестр метрик](../audits/FIN-R1-840-metrics-quality.csv) содержит источник и семантику каждой метрики.

Исполняемая инвентаризация использует `GET /api/v1/forms`, `GET /api/v1/catalog/forms/{code}?locale={locale}`, `GET /api/v1/catalog/contracts/forms/{code}` и дерево `GET /api/v1/catalog/category-tree`. В каждой форме сверены код, версия, уникальность кодов полей, тип, обязательность и режим ввода в обоих представлениях, SHA контракта и наличие кодов метрик у SOURCE_FIELD. Все четыре локали проверены на доступность определения, заголовка и одинаковую идентичность физических полей. SQL подтвердил уникальность 166 кодов форм, 877 пар «версия–код поля» и 840 кодов метрик. Все непустые ссылки полей на метрики разрешились. Утверждение качества переводов остаётся открытым.

Точка входа React — `/`, выбор формы через библиотеку и категорию. Отдельного маршрута URL формы нет. Project ID сохраняется в `fin_intake.lib_form_instance`. API открывает последний снимок по ID экземпляра и организации, историю по номеру редакции. Для тестов значения генерируются из фактического типа MANUAL-поля и фиксированного seed. Версия финансовой политики пока не связывает `REF` и `ENUM` с допустимым справочником. Валюта KZT и месячные периоды берутся из поддерживаемого локального контура. API определения не публикует defaults. Read-only SQL обнаружил ноль записей R16.B в таблицах политик формы и поля для свежего стенда.

Поддерживаемые физические типы по реестру — REF, MONEY, DECIMAL, CODE, DATE, PERIOD, INTEGER, ENUM, TEXT и BOOLEAN. Условие допуска в браузере подтверждено отдельным запросом API для каждой заблокированной формы. Поля без утверждённого режима записи инвентаризированы без создания финансовых данных.
