FIN Form Library — тестовый редактор

Временная MVC / Thymeleaf страница. Сохранение, выгрузка и загрузка работают через действующие REST-контроллеры.

1. Контекст

Для UAT используются демонстрационные UUID. Авторизация и проверка принадлежности пользователю здесь не реализованы.

2. Создание / редактирование

Ревизия: 0

Поля отчёта

Поддерживается SINGLE_RECORD. Значения отправляются полным снимком, не PATCH. Необязательные поля не пропадают при обычном редактировании через эту страницу.

3. Excel — экспорт, Preview, Commit

Сверка сравнивает ревизию, SHA и поля с Preview, затем проверяет сохранность предыдущей ревизии.

Поддерживается только FIN XLSX V2, экспортированный системой. Страницы REPORT и PARAMETERS проверяются сервером. Изменяйте только значения на REPORT.
