# FIN Form Library — проверка генерации моковых шаблонов

Область: `feat/fin-form-library-standalone`, Java 21 / Spring Boot / Liquibase / H2.

**Данные:** только `MOCK_ONLY_NOT_FACT`. Тестовая генерация выполняется в памяти на базе настоящих определений `fin_lib`. В `fin_intake` значения и ревизии **не записываются**; тест фиксирует счётчики записей до и после генерации. Это не утверждённые финансовые отчёты и не дополнительная таблица фактов.

## Тестовые уровни

1. `MockTemplateGeneratorUnitTest` — чистая проверка без Spring: сортировка полей, 2 ориентации, матрица пустых ячеек, запрет авто-0, несовместимые/повторные периоды, неизвестная локаль, повторный код поля, ROWSET и EVIDENCE без выдуманных операций.
2. `MockTemplateCatalogIntegrationTest` — все **166** определений из реального seeded-каталога: контроль кода/версии/состава и того, что 122 `TYPED_DRAFT`, 12 `EVIDENCE_ONLY`, 32 `SCHEMA_NOT_APPROVED` не превращаются в утверждённые формы.
3. Вторая интеграционная проверка генерирует шесть читаемых JSON-макетов и публикует ZIP через GitHub Actions (`fin-form-library-mock-templates`).

## Моковые шаблоны

| Файл в CI | Сценарий |
|---|---|
| `F02-ru-month-COLUMNS.json` | F02, RU, январь-март 2026, показатели по строкам |
| `F02-en-month-ROWS.json` | F02, EN, январь-март 2026, время по строкам |
| `F02-kk-quarter-COLUMNS.json` | F02, KK, Q1–Q2 2026 |
| `F02-zh-Hans-year-ROWS.json` | F02, китайский, два года, время по строкам |
| `DF-CSH-01-ru-ROWSET.json` | Многозаписная форма: колонки есть, фиктивных платежей нет |
| `EVIDENCE-ru-metadata-only.json` | Документальная форма без имитации загрузки вложения |

В каждом шаблоне содержатся `formCode`, `formVersion`, `qualificationState`, `captureMode`, `contentMode`, locale, секции, поля, периоды, оси, состояния MISSING и предупреждения. Любое отсутствующее значение остаётся null; системные коды не переименовываются.

**Границы:** это test-only JSON-макеты из каталога. Генератор универсальной HTML-формы, Excel-экспорт, проверка PostgreSQL и авторизация пока вне этой проверки. Мокирование не означает финансовую квалификацию или готовность всех 166 форм к вводу.

Команда: `mvn --batch-mode -f form-library/pom.xml clean verify`. CI workflow загружает JSON-файлы как downloadable artifact после полного GREEN.
